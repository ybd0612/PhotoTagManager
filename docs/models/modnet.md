## 3. 能力边界

- **只做人像。** MODNet 的训练目标就是肖像 matting（trimap-free）。它**不会**像 u2netp 那样"找画面主体"——实测在一张动漫插画上，它把笔记本电脑和鼠标当背景去掉了，只留人物（见 §5 图 B）。这对"人像抠图"是**正确行为**，但意味着**拿它做通用抠图会丢东西**。
- 通用抠图仍归 Q14（BiRefNet 系），本模型不解决它。
- 不许对用户承诺"发丝级"。发丝档**未验**（§5 未验项 1），当前两张测试图都没有飘散的长发。

## 4. 实测数字（都是开发机 RTX 5060 Laptop，不得当产品承诺）

### 4a. 随机张量定向探针（预热 1 次后 5 次取中位数）

| 日期 | 后端 | 加载 | 推理（中位/最小/首次） | 显存Δ | 内存Δ |
|------|------|------|----------------------|-------|-------|
| 2026-09-29 | DirectML | 132 ms | **131.5 / 126.6 / 148.1 ms** | -5 MiB（噪声） | +40 MB |
| 2026-09-29 | CPU（2 线程） | 115 ms | **250.1 / 248.9 / 329.6 ms** | — | +35 MB |

同批对照（u2netp @320²）：DML 150 ms / CPU 267 ms。**结论：MODNet 在 512²（分辨率高 2.56 倍）上的耗时与 u2netp 在 320² 上基本持平。**

### 4b. 真图 A/B（生产同形管线，DirectML，每张 2 次取均值）

| 图 | 模型 | 加载 | 推理 | 前景占比 |
|---|---|---|---|---|
| 证件照 360×504 | u2netp | 151 ms | 120.5 ms | 0.561 |
| 证件照 360×504 | MODNet | 101 ms | 125.5 ms | 0.561 |
| 插画 1664×1664 | u2netp | 85 ms | 122.5 ms | 0.367 |
| 插画 1664×1664 | MODNet | 99 ms | 137 ms | 0.350 |

⚠️ **口径警告（两条，都必须带着引用）**：
1. 显存增量落在 ±10 MiB 的噪声区，而 `u2netp.md` §4 记的是 **+325 MiB**。两种解释：DirectML 选到了 610M 核显，或算子静默回落 CPU。**这正是 `../design/gpu-self-probe.md` 第 0 步 P1（DirectML 到底选哪块从未验证）未结的那个问题**——本卷宗的耗时只能支撑"跑得通 + 相对量级"，不能当 K3/K6 准入数值。
2. 但**本条决策不依赖 P1**：MODNet 走 CPU 也就 250 ms，无论 DML 最终落在哪块卡，K6（CPU 兜底可用）都成立。

## 5. 真图验收

- **测试图**：① 用户照片库 `个人/7寸.jpg`（真人证件照，短发、纯色蓝底）；② `2024_03_15_21_16_IMG_2848.JPG`（动漫插画，非人像，用来做"不许崩溃"的回归档）。
- **脚本**：`C:\Users\ybd06\temp\ptm-portrait\ab.cjs`（临时产物，未进仓库）。预处理与后处理**逐行复刻** `electron/ai/preprocess.ts` 的等比缩放+居中补边+归一化，和 `postprocess.ts` 的 `cropMaskPlane` → 概率范围判定 → lanczos3 放大 → LA overlay → `dest-in` 合成。
- **管线忠实性校验（关键，它决定 A/B 差异出自模型还是脚本）**：用同一套复刻管线跑 u2netp，与 app **自己产出的** `2024_03_15_21_16_IMG_2848.cutout.png` 逐像素比 alpha 通道 → **平均绝对差 0.00/255，最大 1，差异 >10 的像素占 0.000%**。即我的脚本与生产管线在数值上等价，A/B 可信。
- **肉眼结论（棋盘背景，左 u2netp / 右 MODNet）**：
  - 证件照：两者都完整保住头部与肩部。**u2netp 头缘有一圈可辨的蓝色描边**（背景色残留），**MODNet 这圈明显更干净**；代价是 MODNet 的发际线略微"被啃"，头顶轮廓比 u2netp 少一点点。
  - 插画：u2netp 把人物 + 笔记本 + 桌面留成一片前景（保留了大块浅色背景）；MODNet 只留人物，把笔记本与鼠标当背景去掉。**符合各自训练目标**，不构成质量结论。
- **未验项（不许当成已验）**：
  1. **发丝/碎发档**——两张测试图都没有飘散长发，而这正是 MODNet 相对 u2netp 的主要卖点。**须一张真人长发照**。
  2. **装机版端到端**——只在纯 node 进程跑过，未经 Electron 子进程与真实 UI 链路（`verify:ai-child` 那条路）。
  3. **真实显存/内存峰值**——受 §4 口径警告 1 阻塞。
  4. **CPU 慢速模式界面文案**——现在写的是"比 GPU 慢约一个数量级"，对 MODNet 实测只有 1.9×，属误导（该文案改判已登记在 `project-cpu-gpu-parity-direction`，代码未动）。

## 6. 管线与产物

- 与 u2netp **共用** `portrait-cutout-alpha` 后处理与 `outputSuffix: cutout`，产物形态不变（`原名.cutout.png`，同目录派生，原图不动）。
- **掩码在 512×512 上计算**（u2netp 是 320×320）。分屏对比与"结果变糊"的说明文案要按模型给不同分辨率，不能写死 320——沿用 `u2netp.md` §5 那条"必须注明掩码在 NxN 下计算"的口径。
- sigmoid 判定走**数值范围自动识别**，不按模型名写死：MODNet 首输出值域 `[0, 1]` → 判为概率、不再套一层。这条机制正是为"换模型"准备的，本次是它第一次被第二个模型验证。
- **不影响安装包体积**：模型走下载（`userData/models/`），不随包发。新增 24.69 MB 是**用户按需下载**的磁盘代价，不是 121 MB 安装包的代价。
- 后端切换沿用既有裁定：后端变化必须重建会话、`backend` 不进缓存键、选择不持久化（D12 + §8-16 那三条口径）。
