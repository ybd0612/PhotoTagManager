## 全局约束（每批都隐含遵守）

- 改动先写失败测试再最小实现；**精确 `git add`，禁止 `-A`；不 push**；提交挡在门槛后面（先取 `$?` 判 0）。
- 任务内只跑定向测试；全量单测 + `typecheck` 只在**每批收尾**跑一次；`build` → `dist` 顺序不可省，出包前确认应用已退出。
- 不新增依赖。UI 走 MUI 5 + Tailwind 既有体系，配色走 theme token，**不再手写 rgba**（预览层深色面除外，统一用局部常量）。
- 三条既有不变量不许被顺手改弱：主按钮语义恒定不置灰、hover 不承载动作、下拉可键盘导航；
  以及"设置页不许出现调了没反应的假控件"——**这条在本批会被合法放宽**：只有真的接上行为的控件才允许出现。
- 验证分层：像素（CDP 截图）/ DOM 文本 / 单测。报告里必须标清用了哪层，不许把"应该更好看"写成已验证。

## 批次 0 · 先实测再决定（不写产品代码）

**G0 保存后全根 rescan 的耗时**（3,392 张的库）。用 CDP 点「重新扫描」并轮询状态栏到"扫描已完成"，记墙钟。
- 若 < 1.5s：维持现状。→ **命中此分支，不做 scan:dir 增量刷新**（省一整套 IPC 与合并逻辑）。
- 若 ≥ 1.5s：做**按目录增量刷新**（新增 `scan:dir` IPC，只重扫当前目录并合并 `imagesByDir` + 该目录节点计数），
  保存后与删除后都用它。
判据：实测数字进本文件"实施记录"，不允许拍脑袋。

## 批次 1 · 找图体验（一个提交族，都在网格与筛选链路上）

- **G1 搜索框**：顶栏/筛选条加一个输入框，按**文件名子串**过滤当前目录（大小写不敏感、中文可用）。
  空态要区分"没有匹配"与"目录本来就空"。
- **G2 排序控件**：文件名↑↓ / 拍摄时间↑↓ / 大小↑↓，默认文件名升序；选择持久化到 `settings.json`（这是新偏好，
  与 G6 同一个存储）。排序在渲染层做，不动扫描器。
- **G3 卡片信息层**：文件名条默认不常驻，改 hover/键盘聚焦时以底部渐隐浮现；卡片加标签角标（最多 2 个 chip + `+N`）；
  缩略图容器给浅灰底（白截图不再和背景粘连）。
- **G4 缩略图尺寸档位**：三档（小/中/大，约 150/200/280px），工具栏一个 segmented 控制，持久化同上。
  现有 `FixedSizeGrid` 的 cell 尺寸与 `cols` 计算要跟着变，虚拟滚动的可见区间回调不能失效。

验收：`tests/` 新增过滤/排序/尺寸的纯函数用例（先红后绿）；CDP 截图看三档与搜索态；网格滚动仍流畅。

## 批次 2 · 布局与导航（AppLayout + FolderTree + 状态栏）

- **G5 左栏合并成单棵树**：现在「根目录（2）」与「目录」两块会出现同名条目（截图 / 截图），概念混淆。
  合成一棵树：根为顶层节点、子目录缩进；"已隐藏 N" 与眼睛图标收进 tooltip 或行尾单个图标。
  注意 `roots` 与 `treesByRoot` 的按根分桶逻辑不能破，隐藏集仍按 `rootKey` 生效。
- **G6 顶栏收图标**：「检查更新」「关于」从顶栏移出（收进设置对话框的"关于"分区或一个溢出菜单），
  顶栏只留 添加根目录 + 重新扫描 + 设置；主操作与次操作视觉权重分开。
- **G7 状态栏去重**：`已扫描 N 个文件` 与 `扫描已完成（100%）` 同义，合成一条；扫描中显示进度、完成后不重复播报。

验收：`folders.test.ts` / `app.test.tsx` 相应断言更新；窄窗口（860×600）截图确认不溢出。

## 批次 3 · 设置与预览收尾

- **G8 设置对话框做实**：给「常规」分区放真正生效的偏好（G2 默认排序、G4 缩略图尺寸、扫描完成后是否提示），
  加最小高度让它不再像半成品。**仍然禁止放不生效的控件**。
- **G9 预览动作条分层**：底栏当前五个控件一字排开（原位对比 / 左右双栏 / 按住看原图 / 保存 / 不保存），
  把"模式切换"与"动作"分成两段（左 segmented、右 保存/不保存）；「按住看原图」增加**空格键**按住生效，
  并在图上给一个浮层提示，不再挤在动作条里。
- **G10 预览输入框对比**：暗底上 TextField 的边框 0.25 → 0.35、placeholder 0.45 → 0.6，focus 态给可见高亮。
- **G11 快捷键帮助**：加一个入口（设置内或 `?` 唤出），列出已实现的键盘操作，不承诺未实现的。

验收：`aiUi` / `previewWiring` / `aiCompareView` 三组用例保持全绿并新增键盘与分层断言；CDP 真像素复看预览层。
