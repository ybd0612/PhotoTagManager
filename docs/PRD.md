# PhotoTagManager 产品需求文档（PRD）

> 版本：v0.1（初稿） · 作者：产品经理 许清楚 · 状态：待评审

## 1. 项目信息

| 项目 | 内容 |
|------|------|
| 产品名称 | PhotoTagManager（暂定） |
| 项目代号 | photo_tag_manager |
| 产品形态 | Windows 桌面应用 |
| 技术栈 | Electron + React（Vite + React + MUI + Tailwind CSS） |
| XMP 读写 | exiftool-vendored（JPG/PNG/WebP/RAW/HEIC/TIFF 等） |
| 标签体系 | 自由标签（写入 XMP dc:subject / xmp:Label，无固定分类） |
| 目标平台 | Windows |
| 文档语言 | 中文 |

### 原始需求复述

用户需要一款 Windows 桌面工具：选择图片根目录后扫描其中所有图片，以「仅包含图片的目录树」形式浏览（树结构与电脑一致，但隐藏空目录/无图片目录）；可对文件夹标记显示或不显示（隐藏状态需持久化）；可为每张图片编辑 XMP 自由标签并支持按标签筛选；提供图片预览（大图 + 缩略图网格 + 上一张/下一张）；要求 UI 现代化、处理大数据量目录不卡顿。

## 2. 产品定义

### 2.1 Product Goals

| # | 目标 | 说明 |
|---|------|------|
| G1 | 极速浏览 | 万级图片目录扫描与浏览不卡顿，扫描在后台进行、UI 始终可交互 |
| G2 | 精准管理 | 通过自由标签与标签筛选，让用户快速定位、整理海量图片 |
| G3 | 无损合规 | 标签写入 XMP 元数据，不改动图片像素，与主流生态（Lightroom 等）兼容 |

### 2.2 User Stories

| # | 角色 | 故事 |
|---|------|------|
| US1 | 摄影爱好者 | 我想选择一个根目录并看到扫描进度，这样大目录扫描时我能知道何时完成、还可继续操作 |
| US2 | 摄影爱好者 | 我想以和电脑一致的目录树浏览「仅含图片」的目录，这样我能按拍摄组织快速定位图片 |
| US3 | 摄影爱好者 | 我想隐藏不需要的文件夹，这样目录树中只保留我关心的图片目录 |
| US4 | 摄影师 | 我想给图片添加/删除自由标签，这样我能用关键词组织照片且写回原文件 XMP |
| US5 | 摄影师 | 我想按标签筛选图片，这样我能快速找到所有「婚礼」「风光」等主题照片 |
| US6 | 摄影师 | 我想点击图片预览大图并前后翻看，这样我能快速确认图片内容 |
| US7 | 摄影师 | 我想查看/管理已用过的标签，这样我能统一标签命名、避免同义标签混乱 |

## 3. 技术规范

### 3.1 需求池

| 优先级 | ID | 需求描述 | 验收标准 |
|--------|----|----------|----------|
| P0 | R01 | 选择根目录并递归扫描所有子目录 | 支持任意层级子目录；扫描在后台线程执行，UI 不冻结 |
| P0 | R02 | 扫描进度展示 | 显示已扫描/总文件数（或百分比）；支持取消扫描 |
| P0 | R03 | 目录树仅显示含图片目录 | 目录「递归包含 ≥1 张图片」即显示；空目录/无图片目录不显示 |
| P0 | R04 | 目录树与文件系统结构一致 | 树层级、名称与 Windows 目录一致；支持展开/折叠 |
| P0 | R05 | 文件夹隐藏/显示标记 | 可对目录标记隐藏/取消隐藏；隐藏后该目录及其子树从树中消失 |
| P0 | R06 | 隐藏状态持久化 | 隐藏/显示设置写入本地配置，重启应用后仍然生效 |
| P0 | R07 | 图片 XMP 自由标签增删 | 读取并展示图片已有 Subject/Label；可增删标签并写回 XMP，保留其他字段 |
| P0 | R08 | 按标签筛选 | 选择标签后网格只显示匹配图片；支持多标签组合（默认 AND，可切 OR） |
| P0 | R09 | 缩略图网格 | 以网格展示当前目录图片缩略图，虚拟滚动保证大目录流畅 |
| P0 | R10 | 图片大图预览 | 点击缩略图打开预览；支持上一张/下一张、Esc 关闭 |
| P0 | R11 | 图片格式支持 | 通过 exiftool-vendored 支持 JPG/PNG/WebP/RAW/HEIC/TIFF 等常见格式 |
| P1 | R12 | 标签管理面板 | 汇总所有已用标签及计数；支持重命名/合并标签（批量更新 XMP） |
| P1 | R13 | 图片信息展示 | 预览时展示分辨率、拍摄时间、文件大小等基本信息 |
| P1 | R14 | 批量打标签 | 多选图片后批量添加/删除标签 |
| P1 | R15 | 扫描结果增量更新 | 目录内容变化后可重新扫描并合并结果，不重复加载已有数据 |
| P2 | R16 | 标签搜索 | 输入关键字模糊搜索标签 |
| P2 | R17 | 最近目录 | 记录最近打开的根目录，一键重开 |
| P2 | R18 | 深浅色主题 | 支持深色/浅色主题切换 |

### 3.2 关键设计决策

| 编号 | 决策 | 说明 |
|------|------|------|
| D1 | 目录显示规则 | 目录「递归包含 ≥1 张图片」即显示。扫描时对每目录统计 `directCount`（直接图片数）与 `totalCount`（含递归），`totalCount > 0` 即显示；结果整体缓存于内存，避免展开时重复计算 |
| D2 | 隐藏规则与持久化 | 隐藏作用于目录节点，其所有子目录一并消失；取消隐藏仅恢复该目录本身。隐藏路径列表持久化到 `userData/hiddenFolders.json`，记录相对根目录的路径（根目录变化时隐藏集失效） |
| D3 | 标签存储 | 标签写入图片 XMP `dc:subject`（数组）与 `xmp:Label`（主标签）。读取以 `dc:subject` 合并去重；写入仅更新标签字段，保留 XMP 其他字段。exiftool-vendored 为子进程调用，批量操作需排队/限流 |
| D4 | 性能策略 | ① 扫描在 Worker 线程执行，主线程只接收增量结果（批推送，如每 200 文件推送一次）② 缩略图生成走独立队列 + 磁盘缓存，不重复生成 ③ 缩略图网格虚拟滚动，只渲染可视区域 ④ 目录树懒加载展开 |

**布局说明：**

| 区域 | 说明 |
|------|------|
| 左侧目录树 | 宽约 260px，可折叠；目录节点右键菜单：`隐藏文件夹 / 取消隐藏 / 重新扫描`；隐藏目录以 👁 图标标识（可再次显示） |
| 右侧标签筛选条 | 已选标签以 chips 展示，可单个删除；点「+ 添加筛选」弹出标签选择器（含计数） |
| 右侧缩略图网格 | 虚拟滚动；缩略图右下角显示标签角标；支持多选 |
| 底部状态栏 | 图片总数、选中数、扫描状态与进度条 |
| 预览覆盖层 | 全屏；支持键盘 ←/→ 翻页、Esc 关闭；可在此直接增删标签 |

**核心交互流程：**

1. 启动 → 空状态页，提示「选择根目录」
2. 选择目录 → 后台扫描，状态栏显示进度，目录树随结果逐步填充
3. 点击树节点 → 右侧加载该目录图片缩略图
4. 右键目录 → 隐藏（该目录及子树从树中消失，状态持久化）；「取消隐藏」恢复
5. 点击缩略图 → 预览大图，可打标签、翻页
6. 在标签筛选条选择标签 → 网格只显示匹配图片

### 3.4 Open Questions（待确认）

| # | 问题 | 默认建议 |
|---|------|----------|
| Q1 | 目录树「含图片」判定：仅直接含图片，还是递归含图片即显示？ | 递归含 ≥1 张即显示（D1），实现简单且符合直觉 |
| Q2 | 隐藏文件夹持久化范围：绝对路径还是相对根目录路径？ | 相对路径，根目录变化时隐藏集失效（D2） |
| Q3 | 标签写回时机：立即写回还是手动保存？ | 立即写回（增删即生效），失败时提示重试 |
| Q4 | 多标签筛选逻辑：AND 还是 OR？ | 默认 AND（更精确），UI 提供切换开关 |
| Q5 | 标签重命名/合并（P1）是否纳入首版范围？ | 纳入 P1，不做进 MVP |
| Q6 | 是否需要数据库缓存扫描结果以加速二次启动？ | 首版不做，用内存缓存；后续评估 SQLite |
| Q7 | RAW 缩略图依赖 exiftool 抽取，性能是否可接受？ | 用缓存 + 懒加载缓解；大 RAW 目录需实测验证 |
| Q8 | 隐藏目录是否影响标签统计（图片仍计入全局标签计数）？ | 标签统计不受隐藏影响 |
